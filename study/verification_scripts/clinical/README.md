# Clinical verification and sensitivity analysis

Run `Rscript clinical_sensitivity.R` from this directory. Original project scripts and harmonised matrices are read-only. `PROJECT_REV` and `KIDNEY_DATA` may override the documented original locations. Only the base R installation is needed for the clinical computations. No random sampling is used.

The registered comparisons for this post hoc audit are defined before executing the analysis. The primary reproduction uses all original eligible profiles, unchanged gene membership, the original ≥2-measured-genes-per-direction-arm rule, and the archived clinical models. Sensitivities cross the ≥2/≥3 arm thresholds with (i) original members and (ii) removal from each signature of any gene shared with the union of adjustment proxies; the proxy definitions stay fixed. CKD uses injury plus five composition markers, transplant uses five composition markers. Proxy overlap is listed for all 48 sets; only the 15 signed sets have score analyses. A failed arm falls back to the remaining usable arm exactly as in the original implementation. Neither arm usable is reported as unscorable. All score components are defined within the original cohort before subsetting. Within-CKD analyses subset the cases for correlation estimation rather than recomputing gene scaling.

Multiplicity families are the 15 signed scores separately within cohort, endpoint, population, model, threshold and trimming variant (including a separate model family for each transplant exclusion). BH q values are secondary, reported alongside original-style nominal P and pointwise intervals. All intended 15 members count in these families, even if an arm is unevaluable. Neither pools nor published genes are chosen for significance. The 3 transplant populations are all classified donors, omit the discordant inferred donor, and omit every inferred bilateral donor. Use raw deposited first-kidney labels identically in all populations. Fisher-transformed rank correlation intervals reflect the original statistical approximation; CKD contrast intervals use the fitted linear model residual degrees of freedom. Sensitivity populations do not redefine the main estimand.

Run `python3 audit_sources.py` after the R computation to rebuild the metadata tables and source fingerprints. The checked public records and workbook inventory are under `sources/`; `clinical_verified_figures.csv` is the figure-oriented baseline extract, with panel and statistical unit.
